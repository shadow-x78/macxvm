# MacXVM - حزمة تعريف MXGPU

‏MXGPU هو التعريف الذي يخطط له MacXVM لكرت NVIDIA ممرّر إلى macOS. توضح هذه
الصفحة ما هو موجود في المستودع اليوم: صيغة الحزمة، وجذور الثقة، والبناء على
باني macOS، ومعاملة التثبيت، وحالة العمل.

**الميزة تجريبية.** حلقات النواة، والحزمة المعدنية، ومترجم AIR، ومكونات
الفيديو لم تُكتب بعد. لا شيء هنا يدّعي مسار Metal يعمل، وبوابات الخطة ما
زالت مفتوحة. حالة كل مهمة مسجلة في
[artifacts/mxgpu/execution-ledger.json](../artifacts/mxgpu/execution-ledger.json).

## مكونات التعريف

| المكوّن | المسؤولية |
|---|---|
| `MXRM.kext` | وظيفة PCI، و`BAR`، و`DMA`، والمقاطعات، و`GSP`، والذاكرة، والقنوات، والحواجز، والطاقة وإعادة التعيين |
| `MXKMS` | الأوضاع والرؤوس و`vblank` وإيقاف العرض، داخل `MXRM.kext` |
| `MXFB.kext` | مخزن الإطارات و`EDID` والدقة العالية و`HDR` والتوصيل الساخن والمؤشر |
| `MXAccel.kext` | `IOAccelerator` و`IOGPU` و`IOSurface` والإقامة وال.Cache والإكمال |
| `MXAGDC.kext` | سياسة التحكم بالجهاز، بلا انتحال هوية كرت تجاري |
| `MXMTLDriver.bundle` | كائنات Metal والطوابير والمحرّكات والموارد والحواجز |
| `MXAIR` | مُتحقق shaders AIR وتحويلها إلى SPIR-V |
| `NVK` على XNU | Vulkan وNAK فوق `MXRM` |
| `MXVideo` | فك الترميز والترميز في الضيف |

المصادر تحت `driver/`. الملاحظات التي تصف سلوك كل مكوّن في
`driver/research`، والمكونات التي رُوجعت مثبتة في
`driver/third_party.lock.json`.

## غرفة نظيفة

- لا يُنسخ أي مصدر من Apple ولا برنامج ثابت من NVIDIA ولا كود تعريف آخر إلى
  هذا المستودع.
- تذكر الملاحظات مصدر كل جملة: مواصفة عامة، أو رأس عام مسموح بقراءته، أو
  أثر لضيف أنشأه MacXVM، أو تجربة على عتاد المشغّل.
- مكونات ملف القفل مراجع حتى يُكتب رقم نسختها الدقيق وبصمتها. تبقى بوابة
  الغرفة النظيفة مفتوحة حتى ذلك الحين.
- لا تُنتحل معرّفات كرت تجاري أبدًا. هوية الكرت تأتي من قياسات الكرت.

## صيغة الحزمة

الحزمة أرشيف مضغوط يحتوي:

| الملف | المعنى |
|---|---|
| `manifest.json` | الصيغة وهوية المفتاح والهدف وكل ملف بحجمه وبصمته |
| `manifest.sig` | توقيع Ed25519 للشكل القانوني للبيان |
| `SHA256SUMS` | بصمات ملفات الحزمة |
| `SBOM.json` | مكونات الغير الأصلي مع رخصتها وأصلها |
| `NOTICE` | إشعار إعادة التوزيع |
| `third_party.lock.json` | ملف قفل المكونات التي رُوجعت |

التوقيع يغطي الشكل القانوني للبيان لا الأرشيف، فيمكن إعادة بناء الأرشيف من
دون مفتاح جديد. الشكل القانوني يرتب الملفات ومفاتيح البيان ويرفض المفتاح
المكرر والعدد العشري والبيانات الزائدة.

المتحقق يرفض أي حزمة فيها مسار يخرج من الأرشيف أو مسار مطلق أو رابط أو ملف
خاص أو مسار مكرر أو عدد ملفات كبير أو ملف كبير أو أرشيف يتمدد أكثر من
المسموح. ويرفض أي ملف يختلف حجمه أو بصمته عن البيان، وبيانا لا يطابق
توقيعه مفتاح الإصدار.

## جذور الثقة

| المفتاح | المكان | الاستخدام |
|---|---|---|
| مفتاح الإصدار | `resources/mxgpu-release-public-key.txt` | توقيع الحزم |
| مفتاح نسخ المضيف | `~/.macxvm/keys/backup-key` | توقيع بيان نسخة المضيف |
| مفتاح الشاهد للترحيل | المشغّل | سجل الملكية أثناء الترحيل |

المفاتيح الخاصة خارج المستودع وبصلاحية `root` وحده، ولا تدخل أي حزمة. المفتاح
العام للإصدار هو الذي يستخدمه متحقق MacXVM.

## البناء على باني macOS

تُبنى الحلقات على macOS، ولا تُبنى أبدًا على Linux.

```bash
macxvm driver build --builder user@macos-builder
```

يؤرشف الأمر مجلد `driver/` مع ملف قفله، ويرسله عبر SSH إلى مجلد مؤقت،
ويتحقق أن الأرشيف وصل دون تغيير، ثم ينفذ `make build` و`make test` و
`make package` على الباني، ويجلب الحزمة إلى `artifacts/mxgpu/package/`،
ويتحقق من توقيعها.

على الباني نفسه:

```bash
make -C driver build      # الحلقات مع ARCHS=x86_64 وSDKROOT=macosx
make -C driver test       # اختبارات الباني
make -C driver test-host  # الفحوص التي لا تحتاج إطار macOS
make -C driver package    # الحزمة وSBOM
```

يعمل `make -C driver test-host` على Linux وفي خط أنابيب التكامل: يتحقق من
ملف قفل مكونات الغير الأصلي ومن لافتة الاعتماد في كل مصدر من مصادر التعريف.

## التثبيت داخل ضيف

```bash
macxvm gpu NAME --install-driver PACKAGE --accept-driver-changes
```

تعمل المعاملة بالترتيب:

1. تتحقق من توقيع الحزمة وبصمة كل ملف.
2. تنسخ `NVRAM` والبيان المثبّت وملفات المراحل الثلاث وصور OpenCore.
3. تكتب بيانًا موقّعًا لنسخة المضيف، فيعيد التراجع الحالة نفسها التي وجدها
   التثبيت.
4. تنسخ المكونات إلى الضيف وتكتب البيان المثبّت.
5. تسجل تقرير فحص، ولا تصبح الآلة `gpu-ready` إلا بنجاح ذلك التقرير.

يعيد التراجع النسخة المطابقة للبيان:

```bash
macxvm gpu NAME --remove-driver
macxvm start NAME --display recovery
```

تُقلع مرحلة الاستعادة براية `-mxoff` فلا يلمس التعريف الكرت، ويعود عرض
الضيف إلى `bochs-display` عبر VNC.

## حالة العمل

| البوابة | الحالة |
|---|---|
| G0، الغرفة النظيفة و`SBOM` | مفتوحة: بصمات الأصول المجهزة ناقصة |
| G1، ملكية الكرت | مفتوحة: دورات على العتاد الحقيقي ناقصة |
| G2 إلى G7، التعريف والميزات | مفتوحة: المصادر لم تُكتب |
| G9، الحزمة والتثبيت | مفتوحة: لم تُوقّع أي حزمة ولا تُثبت في ضيف |

سجل الخطة يذكر حالة كل مهمة مع أدلتها.
